7 resources · schema_version 1.0 · languages: en / el

Usage

curl https://dexiotitesmetragoudi.github.io/api/v1/resources.json

Read the resources array and filter locally by language, skill, age_range or download type. IDs are stable within each language catalogue. Links are absolute. Missing optional resources are null. lesson.duration_minutes describes the suggested activity, not the video length. updated_at is the latest included publication date, not the server response time.

This is a static GET endpoint: query parameters do not perform server-side searches. Cache the catalogue and fetch it at most once per day unless you need a refresh. Browser cross-origin access depends on hosting headers; server-side clients can fetch the public URL. There are no write operations, API keys, child profiles or automatic agent registration.

Available fields

id, language, title, skill, age_range, description, published_at, page_url, video_url, thumbnail_url, downloads, activity_prompt, discussion_prompts, lesson, quiz_url and certificate. Quiz and certificate links open the existing browser activity; they are not certificate-issuing API endpoints.

Responsible use

Free for home and classroom use. No new permission for republication, modification, resale or model training is granted by this catalogue. Contact the publisher for uses not covered by the existing site terms.

Keep source links and publisher attribution. Preview materials with an adult before use. These are suggested activities, not a clinically validated programme. Certificates are keepsakes, not qualifications. Creative production is AI-assisted. Do not send names, quiz answers or other child information to this endpoint.
